# 兼职测试案例

| 编号 | 岗位类型 | 输入摘要 | 预期结果 |
|---|---|---|---|
| TC001 | 家教/补习 | 四年级男孩，补习语数英，70元一小时，成都金牛区 | 不应提示刷单；追问家长/机构身份、课时结算、上课安全 |
| TC002 | 门店服务 | 礼宴中心服务员，两天任选一天，13元/h，扣意外险和物资费 | 识别扣费风险；追问扣费依据、门店主体、负责人 |
| TC003 | 活动充场/气氛组 | 气氛充场，酒水免费，可不喝酒，坐着玩，30-60/人 | 追问工作边界、是否陪酒/拉客、返程安全、结算扣款 |

| TC005 | 线上兼职 | 手机操作，日结300，先交99培训费，返还 | 高风险；命中先交费用、刷单垫付、信息模糊 |
| TC006 | 地推促销 | 校园扫码拉新，按单结算，需要领取物料 | 追问主办方、计件规则、物料押金、集合地点 |
| TC007 | 配送/跑腿 | 外卖兼职，需要装备押金，按单结算 | 命中押金风险；追问站点、装备押金、保险责任 |
| TC008 | 信息不足 | 兼职，轻松简单，工资面议，加微信详聊 | 中风险；追问主体、内容、薪资、地点、收费 |
