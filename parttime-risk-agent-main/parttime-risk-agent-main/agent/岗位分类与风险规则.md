# 岗位分类与风险规则

## 1. 岗位分类

系统先判断兼职属于哪一类，再生成对应追问，避免把某一类兼职风险误套到另一类岗位。

| 岗位类型 | 关键词示例 | 追问重点 |
|---|---|---|
| 家教/补习 | 家教、补习、辅导、年级、语数英、课时 | 家长/机构身份、课时结算、上课地点安全、是否中介收费 |
| 门店服务 | 服务员、收银、传菜、餐饮、奶茶、咖啡、门店 | 门店名称、班次、日薪/时薪、服装费、押金 |
| 短期活动/会务协助 | 酒店、会议、会务、PPT、播音、宣讲、签到、接待 | 活动主办方、当天工资、考勤、设备要求、是否额外收费或垫付 |
| 活动充场/气氛组 | 充场、气氛组、酒水、鼓掌、坐着玩、夜场 | 工作边界、是否陪酒/拉客/营销酒水、返程安全、扣款规则 |
| 地推促销 | 传单、地推、促销、扫码、拉新 | 主办方、集合地点、计件规则、物料押金 |
| 配送/跑腿 | 配送、跑腿、骑手、外卖、快递、分拣 | 平台/站点、车辆装备、保险责任、装备押金 |
| 线上兼职 | 线上、手机操作、打字、录入、任务 | 是否刷单、垫付、充值、返利、索要敏感信息 |

## 2. 风险类别

| 风险类别 | 判断依据 | 分值建议 |
|---|---|---|
| 先交费用 | 押金、保证金、报名费、培训费、服装费、资料费 | 40 |
| 刷单垫付 | 刷单、做单、充值、返利、先付款、解冻 | 55 |
| 信息模糊 | 工作内容笼统、只说简单轻松、只让加微信详聊 | 15 |
| 隐私索取 | 验证码、银行卡、身份证照片、人脸识别 | 35 |
| 用工不规范 | 无合同、试用期无薪、工资另算、月底看情况 | 25 |
| 工作边界 | 充场、气氛组、酒水、陪酒、拉客、强制消费 | 20 |
| 现场安全 | 夜场、酒吧、KTV、晚间活动、返程不明确 | 15 |

## 3. 追问护栏

Agent 追问必须遵守以下限制：

1. 原文已经写明的信息不重复追问。
2. 短期一天兼职不追问试用期、长期排班、周结或月结。
3. 原文没有线上资金任务线索时，不追问刷单、充值、返利、拉人、转账。
4. 家教类岗位不使用线上兼职话术。
5. 充场和气氛组重点追问工作边界和现场安全。
6. 会务协助重点追问主办方、工资发放、考勤方式和设备费用。

## 4. 大模型提示词原则

大模型只负责辅助生成追问和解释报告，不直接决定系统全部结果。系统会在大模型输出后进行规则过滤，删除与当前岗位无关的问题，保证追问贴合兼职文本。
