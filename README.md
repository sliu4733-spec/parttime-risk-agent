# 兼职岗位风险检查 Agent

当前扩展版本：**3.0.16**。这是面向求职场景的浏览器扩展，配套本机账号与记录服务。使用说明见 [本机演示说明](本机演示说明.md)。

## 功能

- 分析当前招聘网页、手动粘贴的文本，或通过自配视觉模型识别截图。
- 结合招聘内容与用户回答进行风险筛查，生成证据、解释和入职前核实清单。
- 信息不足时追问，允许按现有信息生成报告；未知信息不自动视为诈骗事实。
- “时间自由”“双休”“工资面议”“酒水”等普通描述不单独计分，结合行为和上下文判断。
- 保存本机历史、复制及导出报告；登录后可主动将选定记录保存到本机后端。
- 识图模型与回答模型分别配置。模型不可用时显示真实错误，文本分析可回退本地规则。

## 安装与运行

1. 安装 Node.js 20 或更高版本。
2. 如需注册、登录和账号记录，双击 `启动后端.cmd`，或在 `server` 目录执行 `npm ci` 后执行 `npm start`。保持服务运行。
3. 在 Chrome / Edge 的扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，加载 `extension` 文件夹。
4. 游客检测无需启动后端；可选大模型功能需要在“规则与 API 设置”中填写自己可用的接口、模型名称与 API Key，并保存。
5. 更新已有扩展后点击重新加载，并刷新招聘页面。

服务固定监听 `127.0.0.1:3000`，健康检查地址为 `http://127.0.0.1:3000/api/health`。本版不提供局域网跨电脑登录：账号和数据属于当前电脑，其他电脑需要自行运行服务并注册。

## 数据与隐私

- 后端使用 Express + sql.js（SQLite），首次启动自动创建 `server/data/sync.sqlite`，无需安装 MySQL。
- 浏览器 `chrome.storage.local` 保存本机草稿、历史和模型设置；后端按账号隔离保存用户、会话与记录。
- 只有用户同意并主动同步时，才向本机后端发送所选招聘文本、问答与报告。API Key、密码和截图原文件不作为记录同步。
- 截图识别会把图片发送到用户配置的模型接口，区别于记录同步。
- 数据库、密钥、依赖目录和本地模型输出不纳入 Git。数据库备份前先停止服务；本实现适用于单进程课程演示。

## 测试

在 `server` 目录执行 `npm ci` 和 `npm test`。当前回归测试共 51 项，覆盖页面提取、规则与追问、模型协议、界面及账号记录同步。自动测试使用模拟页面和模型响应，不代表真实网站或任意模型接口都已验证。

## 目录

- `extension/`：浏览器扩展、页面提取、风险规则、模型调用与界面。
- `server/`：本机账号及 SQLite 记录服务。
- `tests/`：自动回归测试和需单独启用的真实模型测试脚本。

风险等级是辅助筛查结果，不是诈骗概率，也不构成安全保证。模型可用性取决于接口、模型权限及对应服务商配置。
