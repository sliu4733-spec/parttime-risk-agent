# 需求规格说明书

## 1. 项目名称

面向大学生的兼职岗位风险检查 Agent

## 2. 项目背景

大学生寻找兼职时，经常通过微信群、社群、招聘网站获取岗位信息。这些信息质量参差不齐，可能存在押金、刷单、垫付、薪资不明确、工作边界模糊、隐私索取等风险。普通招聘平台能发布岗位，但不一定能针对大学生兼职场景进行解释型风险检查。

## 3. 项目目标

系统通过 Chrome 插件读取或粘贴兼职招聘文本，调用后端 Agent 服务进行风险检测。如果信息不足，Agent 主动提出追问；如果信息足够，生成风险等级、风险分数、证据片段和处理建议。

## 4. 核心功能

1. 兼职招聘文本输入与网页抓取。
2. 岗位类型识别。
3. 风险规则扫描。
4. 风险评分与等级判断。
5. Agent 场景化追问。
6. 用户多轮补充回答。
7. 风险报告生成。
8. 检测历史保存。
9. 风险规则维护。
10. 大模型 API 中转。

## 5. 非功能需求

1. 易用性：学生用户点击插件即可完成检测。
2. 可解释性：报告需要展示命中规则和证据片段。
3. 可维护性：风险规则可新增、修改和删除。
4. 安全性：正式部署时 API Key 不应保存在浏览器端，应由后端中转。
5. 可靠性：大模型调用失败时，系统仍可使用本地规则生成结果。

## 6. 排除范围

本项目不实现完整招聘平台，不实现岗位发布、简历投递、在线支付、用户聊天、企业认证和真实劳动仲裁服务。
